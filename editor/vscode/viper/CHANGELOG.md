# Changelog

## 1.1.1

First marketplace release, matching Viper 0.0.1 (the first official, non-beta
version of the language).

- Syntax highlighting for `.vp`
- LSP client: autocompletion with signatures and docs, dot-completion for
  Python and Viper modules, hover docs, signature help, live diagnostics
  (type errors + lint warnings)
- Keyword/buffer fallback completions when the language server is unavailable
- `viper.lspPath` setting
